# Prather Bytecraft Homebrew tap

Homebrew formulas for Prather Bytecraft apps.

## Startbar

A taskbar for macOS. See https://github.com/pratherbytecraft/startbar.

```
brew install pratherbytecraft/tap/startbar
startbar
```

## Filedrawer

A file manager for macOS. See https://github.com/pratherbytecraft/filedrawer.

```
brew install pratherbytecraft/tap/filedrawer
filedrawer
```

## Shotdrawer

A menu bar app for macOS that lists your recent screenshots. See https://github.com/pratherbytecraft/shotdrawer.

```
brew install pratherbytecraft/tap/shotdrawer
shotdrawer
```

## Help

Open an issue on the app's GitHub page: https://github.com/pratherbytecraft/startbar/issues, https://github.com/pratherbytecraft/filedrawer/issues or https://github.com/pratherbytecraft/shotdrawer/issues.
